تنسيقات النصوص الإضافية

في المحاضرة الأولى تعلمنا <strong> و <em>. الآن سنتعلم المزيد:

الـ Tagالوظيفةمثال
<mark> تحديد النص (Highlight) نص محدد
<del> نص محذوف (خط في الوسط) نص محذوف
<ins> نص مُضاف (خط تحته) نص مُضاف
<small> نص صغير نص صغير
<sub> نص منخفض (Subscript) H2O
<sup> نص مرتفع (Superscript) X2

💡 مثال عملي:

text-format.html
<p>
    السعر الأصلي <del>100 جنيه</del>
</p>
<p>
    السعر الجديد <mark>75 جنيه</mark>
</p>
<p>
    الماء هو H<sub>2</sub>O
</p>

السعر الأصلي 100 جنيه

السعر الجديد 75 جنيه

الماء هو H2O

القوائم (Lists)

القوائم من أهم العناصر في HTML. نستخدمها في:

  • قوائم المهام
  • القوائم المنسدلة (Menus)
  • عرض البيانات المنظمة
  • السير الذاتية (CVs)

📋 1. القائمة غير المرتبة (Unordered List)

تُستخدم عندما لا يكون الترتيب مهماً. تظهر بنقاط (bullets).

unordered-list.html
<h3>هواياتي المفضلة</h3>
<ul>
    <li>البرمجة</li>
    <li>القراءة</li>
    <li>الرياضة</li>
    <li>الرسم</li>
</ul>

هواياتي المفضلة

  • البرمجة
  • القراءة
  • الرياضة
  • الرسم

🔢 2. القائمة المرتبة (Ordered List)

تُستخدم عندما يكون الترتيب مهماً. تظهر بأرقام.

ordered-list.html
<h3>خطوات تعلم البرمجة</h3>
<ol>
    <li>تعلم HTML</li>
    <li>تعلم CSS</li>
    <li>تعلم JavaScript</li>
    <li>بناء المشاريع</li>
</ol>

خطوات تعلم البرمجة

  1. تعلم HTML
  2. تعلم CSS
  3. تعلم JavaScript
  4. بناء المشاريع
💡 نصيحة: استخدم <ul> للأشياء غير المرتبة، و <ol> للخطوات أو الترتيب.

🔄 3. القوائم المتداخلة (Nested Lists)

يمكنك وضع قائمة داخل قائمة أخرى:

nested-list.html
<h3>مهاراتي</h3>
<ul>
    <li>البرمجة
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>
    <li>التصميم
        <ul>
            <li>Photoshop</li>
            <li>Figma</li>
        </ul>
    </li>
</ul>

مهاراتي

  • البرمجة
    • HTML
    • CSS
    • JavaScript
  • التصميم
    • Photoshop
    • Figma

الروابط (Links)

الروابط هي أساس الإنترنت! تُستخدم لـ:

  • الانتقال بين الصفحات
  • فتح مواقع خارجية
  • تحميل ملفات
  • إرسال بريد إلكتروني

🔗 شكل الرابط الأساسي

link-basic.html
<a href="https://www.google.com">اذهب إلى جوجل</a>

📖 شرح الأجزاء:

  • <a> = Anchor (رابط)
  • href = Hypertext Reference (عنوان الصفحة)
  • النص بين <a> و </a> هو الذي يظهر للمستخدم

🌐 أمثلة على الروابط

رابط خارجي

external.html
<a href="https://youtube.com">
    يوتيوب
</a>

رابط داخلي (صفحة أخرى)

internal.html
<a href="about.html">
    عن الموقع
</a>

🎯 فتح الرابط في نافذة جديدة

new-tab.html
<a href="https://github.com" target="_blank">
    GitHub (يفتح في تاب جديد)
</a>
⚠️ مهم: target="_blank" يفتح الرابط في تاب جديد.

📧 رابط بريد إلكتروني

email-link.html
<a href="mailto:info@example.com">
    راسلنا
</a>

التعليقات (Comments)

التعليقات هي ملاحظات نكتبها في الكود:

  • ✅ لا تظهر في المتصفح
  • ✅ تساعدك على تذكر ما فعلت
  • ✅ تساعد الآخرين على فهم الكود
  • ✅ مفيدة في المشاريع الكبيرة
comments.html
<!-- هذا تعليق لن يظهر في المتصفح -->

<h1>مرحباً</h1>

<!-- 
    يمكن كتابة تعليق
    على عدة أسطر
-->

<p>هذا نص يظهر</p>

<!-- <p>هذا نص معطّل بالتعليق</p> -->
💡 نصيحة: استخدم التعليقات لتنظيم الكود وتوضيح الأجزاء المهمة.

المشروع العملي: صفحة CV بسيطة

الآن سنبني معاً سيرة ذاتية بسيطة باستخدام كل ما تعلمناه! 🎉

cv.html
<!DOCTYPE html>
<html lang="ar">
<head>
    <meta charset="UTF-8">
    <title>السيرة الذاتية - أحمد محمد</title>
</head>
<body>
    <!-- القسم الأول: المعلومات الشخصية -->
    <h1>أحمد محمد علي</h1>
    <h2>طالب في Sunshine T Academy</h2>
    
    <hr>
    
    <!-- معلومات الاتصال -->
    <h3>معلومات الاتصال</h3>
    <ul>
        <li>البريد: <a href="mailto:ahmed@example.com">ahmed@example.com</a></li>
        <li>GitHub: <a href="https://github.com" target="_blank">github.com/ahmed</a></li>
    </ul>
    
    <!-- عني -->
    <h3>عن نفسي</h3>
    <p>
        أنا طالب متحمس لتعلم <strong>تطوير الويب</strong>.
        <br>
        هدفي أن أصبح <mark>Full Stack Developer</mark> محترف.
    </p>
    
    <!-- المهارات -->
    <h3>مهاراتي التقنية</h3>
    <ul>
        <li>HTML
            <ul>
                <li>العناوين والفقرات</li>
                <li>القوائم والروابط</li>
            </ul>
        </li>
        <li>CSS <small>(قريباً)</small></li>
        <li>JavaScript <small>(قريباً)</small></li>
    </ul>
    
    <!-- التعليم -->
    <h3>المسار التعليمي</h3>
    <ol>
        <li>تعلم HTML ✓</li>
        <li>تعلم CSS (جاري)</li>
        <li>تعلم JavaScript</li>
        <li>بناء مشاريع حقيقية</li>
    </ol>
    
    <!-- الهوايات -->
    <h3>هواياتي</h3>
    <ul>
        <li>البرمجة 💻</li>
        <li>القراءة 📚</li>
        <li>الرياضة ⚽</li>
    </ul>
    
    <hr>
    
    <p>
        <small>آخر تحديث: 2024</small>
    </p>
</body>
</html>
💡 تحدي: اكتب نفس المشروع ولكن بمعلوماتك الشخصية!

ملخص المحاضرة

✅ ما تعلمناه اليوم

  • تنسيقات النصوص: mark, del, ins, small, sub, sup
  • القوائم غير المرتبة <ul> والمرتبة <ol>
  • عنصر القائمة <li>
  • القوائم المتداخلة (Nested Lists)
  • الروابط <a> و href و target
  • التعليقات <!-- -->
  • بنينا صفحة CV كاملة!

🧠 اختبر نفسك — 10 أسئلة

السؤال 1: ما هو الـ tag المستخدم لإنشاء قائمة غير مرتبة؟

  • A) <ol>
  • B) <ul>
  • C) <list>
  • D) <li>

السؤال 2: ما هو الـ tag المستخدم لعناصر القائمة؟

  • A) <item>
  • B) <li>
  • C) <list>
  • D) <element>

السؤال 3: ما معنى href في الروابط؟

  • A) Hypertext Reference
  • B) High Reference
  • C) HTML Reference
  • D) Home Reference

السؤال 4: كيف نفتح رابط في نافذة جديدة؟

  • A) window="new"
  • B) target="_blank"
  • C) open="new"
  • D) newtab="true"

السؤال 5: ما هو الـ tag لتحديد النص (highlight)؟

  • A) <highlight>
  • B) <mark>
  • C) <select>
  • D) <yellow>

السؤال 6: كيف نكتب تعليق في HTML؟

  • A) // تعليق
  • B) /* تعليق */
  • C) <!-- تعليق -->
  • D) # تعليق

السؤال 7: ما الفرق بين <ul> و <ol>؟

  • A) ul للنقاط، ol للأرقام
  • B) ul للأرقام، ol للنقاط
  • C) لا يوجد فرق
  • D) ul للعناوين، ol للفقرات

السؤال 8: ما هو الـ tag لكتابة نص صغير؟

  • A) <tiny>
  • B) <small>
  • C) <mini>
  • D) <little>

السؤال 9: كيف نعمل رابط بريد إلكتروني؟

  • A) href="email:..."
  • B) href="mail:..."
  • C) href="mailto:..."
  • D) href="send:..."

السؤال 10: أي من الآتي صحيح لقائمة متداخلة؟

  • A) نضع <ul> داخل <li>
  • B) نضع <li> داخل <ul> داخل <li>
  • C) لا يمكن عمل قوائم متداخلة
  • D) نستخدم <nested>

📝 الواجب — 5 مسائل

المسألة 1: قائمة المشتريات

المطلوب: أنشئ صفحة HTML تحتوي على:

  • عنوان: "قائمة مشترياتي"
  • قائمة غير مرتبة بـ 6 أشياء تريد شراءها
  • استخدم <mark> على أهم شيء في القائمة

المسألة 2: خطوات صنع شطيرة

المطلوب: اكتب قائمة مرتبة بخطوات صنع شطيرة (5 خطوات على الأقل)

المسألة 3: صفحة روابط مفيدة

المطلوب: أنشئ صفحة تحتوي على:

  • عنوان: "مواقع مفيدة للتعلم"
  • قائمة غير مرتبة بـ 5 روابط لمواقع تعليمية
  • كل الروابط تفتح في تاب جديد

المسألة 4: قائمة متداخلة - المواد الدراسية

المطلوب: أنشئ قائمة متداخلة:

  • القائمة الرئيسية: موادك الدراسية (3 مواد)
  • تحت كل مادة: 3 مواضيع تدرسها فيها

المسألة 5: صفحة CV الخاصة بك

المطلوب: أنشئ سيرة ذاتية كاملة لك تحتوي على:

  • اسمك ووصف قصير عنك
  • معلومات الاتصال (بريد وهمي)
  • قائمة بمهاراتك
  • قائمة مرتبة بأهدافك
  • قائمة بهواياتك
  • على الأقل 3 روابط
  • استخدم التعليقات لتنظيم الكود
💡 نصيحة: اكتب الكود بنفسك، جرّب، واستمتع بالتطبيق!
