HTML Elements & Content

هنشوف أهم عناصر HTML اللي هتستخدمها في كل صفحة: Headings, Paragraphs, Lists, Links, Images، وإزاي ننظم ملفات مشروعك صح.

🔄
مراجعة سريعة

📚 من المحاضرة اللي فاتت

  • Web Development = بناء المواقع على الإنترنت
  • Frontend = الواجهة الأمامية (HTML + CSS + JS)
  • HTML = لغة توصيف لبناء هيكل الصفحة
  • هيكل الصفحة: DOCTYPE → html → head → body
  • head = معلومات الصفحة، body = المحتوى الظاهر

🎯 هدف النهاردة

هنشوف العناصر (Elements) اللي جوه الـ body، وإزاي نستخدمها لبناء محتوى حقيقي. كمان هنتعلم إزاي ننظم ملفات المشروع من البداية — وهي مهارة مهمة جداً لأي Developer محترف.

🧱
Elements, Tags, Attributes

📖 المفاهيم الأساسية

قبل ما ندخل في العناصر، لازم نفهم 3 مصطلحات مهمة:

<p>...</p>
Element (العنصر)

الوحدة الأساسية في HTML. مكون من Opening Tag + Content + Closing Tag

<tag>
Tag (الوسم)

العلامة اللي بتفتح أو بتقفل العنصر. زي: <p> أو </p>

attr="value"
Attribute (الصفة)

معلومات إضافية جوه الـ Opening Tag. زي: href, src, class, id

تشريح Element 
<!-- ده Element كامل -->
<a href="https://example.com">اضغط هنا</a>

<!-- Opening Tag: <a href="..."> -->
<!-- Content: "اضغط هنا" -->
<!-- Closing Tag: </a> -->
<!-- Attribute: href="https://example.com" -->

💡 تشبيه من الحياة

  • Element = الأوضة كاملة (حيطة + أثاث + الناس جواها)
  • Tag = باب الأوضة (اللي بيدخل واللي بيخرج)
  • Attribute = مواصفات الباب (لونه، مقاسه، قفله)

📌 Self-Closing Tags

في عناصر ما بتقفلش لأن مفيش جواها محتوى. زي: <img>, <br>, <hr>, <input>

📰
Headings — العناوين

🔹 مستويات العناوين

في HTML عندنا 6 مستويات من العناوين، من <h1> (الأكبر والأهم) لـ <h6> (الأصغر).

HTML 
<h1>عنوان رئيسي — الأهم في الصفحة</h1>
<h2>عنوان فرعي</h2>
<h3>عنوان أصغر</h3>
<h4>عنوان المستوى الرابع</h4>
<h5>عنوان المستوى الخامس</h5>
<h6>عنوان المستوى السادس — الأصغر</h6>

⚠️ قواعد مهمة للعناوين

1. استخدم <h1> مرة واحدة فقط في كل صفحة (العنوان الرئيسي).

2. متقفزش من <h2> لـ <h4> مباشرة — اتبع الترتيب.

3. العناوين مهمة جداً لـ SEO و Accessibility (القراءات الصوتية).

📝
Paragraphs & Text Formatting

🔹 الفقرات <p>

نستخدم <p> لكتابة أي فقرة نصية. المتصفح بيضيف مسافة تلقائياً بين الفقرات.

HTML 
<p>دي أول فقرة في الصفحة.</p>
<p>ودي فقرة تانية، المتصفح هيفصل بينهم بمسافة.</p>

🔹 عناصر النص الأخرى

العنصر الوظيفة مثال
<br> سطر جديد (Break) سطر أول
سطر تاني
<hr> خط أفقي فاصل ─────
<strong> نص مهم (bold + معنى) مهم جداً
<em> تأكيد (italic + معنى) تأكيد
<mark> نص مظلل (أصفر) مظلل
<small> نص صغير حقوق النشر
<sub> نص سفلي (H₂O) H2O
<sup> نص علوي (x²) x2
مثال شامل 
<p>
    الماء تركيبه الكيميائي هو H<sub>2</sub>O.
    <br>
    معادلة المساحة: م = ط <sup>2</sup>
</p>

<p>
    ده نص <strong>مهم جداً</strong>، وده <em>تأكيد</em>.
    <br>
    وكلمة <mark>مظلة</mark>.
</p>

💡 نصيحة احترافية

استخدم <strong> بدل <b>، و <em> بدل <i>. السبب؟ لأن <strong> و <em> ليهم معنى دلالي (Semantic) — بيوضحوا للمتصفح ومحركات البحث إن النص ده مهم أو فيه تأكيد.

📋
Lists — القوائم

🔹 أنواع القوائم

في HTML عندنا 3 أنواع من القوائم:

<ul>
Unordered List

قائمة غير مرتبة (نقط). للترتيب مش مهم.

<ol>
Ordered List

قائمة مرتبة (أرقام). للترتيب مهم.

<li>
List Item

عنصر واحد داخل القائمة (داخل ul أو ol).

قوائم 
<!-- قائمة غير مرتبة (نقط) -->
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

<!-- قائمة مرتبة (أرقام) -->
<ol>
    <li>افتح VS Code</li>
    <li>اعمل ملف جديد</li>
    <li>احفظ الملف بامتداد .html</li>
</ol>

🔹 القوائم المتداخلة (Nested Lists)

ممكن تحط قائمة جوه قائمة تانية. ده بيحصل كتير في القوائم الفرعية.

Nested Lists 
<ul>
    <li>
        Frontend
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>
    <li>
        Backend
        <ul>
            <li>Node.js</li>
            <li>Python</li>
        </ul>
    </li>
</ul>

🔗
Links — الروابط

🔹 عنصر <a> (Anchor)

الروابط هي قلب الويب. من غيرها مفيش ويب أصلاً. بنستخدم عنصر <a> لإنشاء رابط.

HTML 
<!-- رابط خارجي -->
<a href="https://google.com">روح Google</a>

<!-- رابط يفتح في Tab جديدة -->
<a href="https://google.com" target="_blank">
    افتح في Tab جديدة
</a>

<!-- رابط لصفحة تانية في نفس المشروع -->
<a href="about.html">صفحة About</a>

<!-- رابط بـ title (Tooltip) -->
<a href="contact.html" title="تواصل معانا">
    Contact
</a>

🔍 أهم Attributes للروابط

Attribute الوظيفة مثال
href عنوان الرابط (مطلوب) href="https://..."
target فين يفتح الرابط target="_blank"
title Tooltip عند الوقوف title="معلومة"
rel العلاقة بين الصفحات (للأمان) rel="noopener noreferrer"

⚠️ أمان مهم

لما تستخدم target="_blank" مع رابط خارجي، ضيف rel="noopener noreferrer" لأسباب أمنية:

<a href="..." target="_blank" rel="noopener noreferrer">

🖼️
Images — الصور

🔹 عنصر <img>

عنصر <img> Self-closing — مفيش له Closing Tag. بيستخدم لعرض الصور في الصفحة.

HTML 
<!-- صورة بسيطة -->
<img src="photo.jpg" alt="وصف الصورة">

<!-- صورة بمقاس محدد -->
<img src="logo.png" alt="شعار الشركة" width="200">

<!-- صورة من الإنترنت -->
<img src="https://example.com/image.jpg" alt="وصف">

🔍 أهم Attributes للصور

Attribute الوظيفة ملاحظات
src مصدر الصورة (مطلوب) مسار الملف أو رابط
alt نص بديل (مطلوب) يظهر لو الصورة ما حملتش + للقراءات الصوتية
width عرض الصورة بالبكسل
height ارتفاع الصورة بالبكسل

🚨 ممنوع تنسى alt!

Attribute alt إلزامي مش اختياري. ليه؟

1. Accessibility: المكفوفين بيسمعوا الوصف ده عن طريق قارئ الشاشة.

2. SEO: محركات البحث بتفهم الصورة من الـ alt.

3. Fallback: لو الصورة ما حملتش، النص ده بيظهر مكانها.

💬
Comments — التعليقات

🔹 إزاي تضيف تعليقات

التعليقات نص بيظهر في الكود بس، مش في الصفحة. مهمة جداً لتنظيم الكود وشرحه لنفسك أو لفريقك.

HTML 
<!-- ده تعليق -->
<!-- ده تعليق متعدد الأسطر
     ممكن يكتب أكتر من سطر -->

<h1>مرحباً</h1> <!-- العنوان الرئيسي -->
<p>فقرة تعريفية</p> <!-- الوصف -->

✅ Best Practice

استخدم التعليقات عشان:

• تقسّم الكود لأقسام واضحة (Header, Main, Footer).

• تشرح ليه كتبت كود معين.

• تخبي كود مؤقتاً وقت التطوير (مش للحذف).

📁
تنظيم ملفات المشروع

🔹 ليه التنظيم مهم؟

أي مشروع حقيقي فيه مئات الملفات. لو مش منظم، هتضيع وقتك وانت بتدور. المحترفين بينظموا ملفات المشروع من أول يوم.

Project Structure 
my-website/
├── index.html          ← الصفحة الرئيسية
├── about.html          ← صفحة About
├── contact.html        ← صفحة Contact
├── images/             ← مجلد الصور
│   ├── logo.png
│   ├── hero.jpg
│   └── team/
├── css/                ← مجلد ملفات CSS (لاحقاً)
│   └── style.css
├── js/                 ← مجلد ملفات JS (لاحقاً)
│   └── script.js
└── README.md           ← وصف المشروع

💡 تشبيه من الحياة

  • index.html = باب البيت الرئيسي
  • images/ = ألبوم الصور
  • css/ = دولاب الملابس (التصميم)
  • js/ = صندوق الأدوات (التفاعل)

⚠️ قواعد الأسماء

1. استخدم أحرف صغيرة فقط (lowercase).

2. افصل بين الكلمات بـ dash (-) مش underscore (_) أو مسافة.

3. ممنوع المسافات في أسماء الملفات.

4. الصفحة الرئيسية لازم اسمها index.html.

🔹 أنواع المسارات (Paths)

النوع المعنى مثال
Relative مسار نسبي من الملف الحالي images/photo.jpg
Absolute رابط كامل من الإنترنت https://...
Parent الرجوع لمجلد أعلى ../images/photo.jpg

مشروع المحاضرة: My Hobby

📋 المطلوب

ابني صفحة "My Favorite Hobby" عن هوايتك المفضلة تحتوي على:

  • ✓ عنوان رئيسي <h1> باسم الهواية
  • ✓ فقرة تعريفية <p> فيها شرح
  • ✓ عنوان فرعي <h2> "ليه بحبها"
  • ✓ قائمة <ul> فيها 3 أسباب
  • ✓ عنوان فرعي <h2> "خطوات البداية"
  • ✓ قائمة مرتبة <ol> فيها 4 خطوات
  • ✓ صورة <img> تمثل الهواية مع alt
  • ✓ رابط <a> لموقع مفيد عن الهواية
  • ✓ تعليقات <!-- --> لتنظيم الكود
مثال للحل 
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>هوايتي المفضلة</title>
</head>
<body>

    <!-- العنوان الرئيسي -->
    <h1>القراءة</h1>
    <p>
        القراءة هي <strong>هوايتي المفضلة</strong>
        ، بحب أقرأ كتب متنوعة في مواضيع كتير.
    </p>

    <!-- ليه بحب القراءة -->
    <h2>ليه بحب القراءة؟</h2>
    <ul>
        <li>بيوسّع المعرفة</li>
        <li>بتحسّن التركيز</li>
        <li>بتقلل التوتر</li>
    </ul>

    <!-- خطوات البداية -->
    <h2>خطوات البداية</h2>
    <ol>
        <li>اختار كتاب يناسب اهتمامك</li>
        <li>حدد وقت يومي للقراءة</li>
        <li>ابدأ بـ 15 دقيقة يومياً</li>
        <li>سجّل ملاحظاتك</li>
    </ol>

    <!-- صورة -->
    <img src="images/books.jpg" alt="مجموعة كتب">

    <!-- رابط مفيد -->
    <p>
        لمزيد من الكتب: 
        <a href="https://goodreads.com" target="_blank" rel="noopener">
            Goodreads
        </a>
    </p>

</body>
</html>

📌 ملخص المحاضرة

  • Element = Tag + Content + Closing Tag
  • Attribute = معلومات إضافية جوه Opening Tag
  • Headings من h1 لـ h6 — h1 مرة واحدة في الصفحة
  • Paragraphs <p> + عناصر النص: strong, em, mark, br, hr
  • Lists: ul (غير مرتبة)، ol (مرتبة)، li (العنصر)
  • Links <a> مع href, target, title, rel
  • Images <img> مع src, alt (إلزامي)، width, height
  • Comments <!-- --> لتنظيم الكود
  • تنظيم الملفات: index.html + images/ + css/ + js/
  • أسماء الملفات: lowercase + dash، بدون مسافات

أسئلة اختيار من متعدد

10 أسئلة لاختبار فهمك لمحتوى المحاضرة

سؤال 1

ما هو الـ HTML Element؟

  • أ مجرد Opening Tag فقط
  • ب Opening Tag + Content + Closing Tag
  • ج Attribute داخل الـ Tag
  • د ملف CSS منفصل
سؤال 2

كم مرة يجب استخدام <h1> في الصفحة الواحدة؟

  • أ أي عدد من المرات
  • ب مرتين على الأقل
  • ج مرة واحدة فقط
  • د ممنوع استخدامه
سؤال 3

ما هو الفرق بين <strong> و <b>؟

  • أ مفيش فرق، الاتنين نفس الحاجة
  • ب <strong> ليه معنى دلالي (مهم)، <b> مجرد تنسيق
  • ج <b> أفضل من <strong>
  • د <strong> للـ CSS بس
سؤال 4

أي عنصر بيستخدم لإنشاء سطر جديد داخل فقرة؟

  • أ <hr>
  • ب <br>
  • ج <newline>
  • د <break>
سؤال 5

ما هو العنصر المستخدم لإنشاء قائمة غير مرتبة؟

  • أ <ol>
  • ب <dl>
  • ج <ul>
  • د <list>
سؤال 6

أي Attribute في عنصر <a> يحدد عنوان الرابط؟

  • أ src
  • ب link
  • ج href
  • د url
سؤال 7

ليه Attribute "alt" في <img> مهم جداً؟

  • أ لتحديد حجم الصورة
  • ب لـ Accessibility و SEO و Fallback
  • ج لتحديد لون الصورة
  • د اختياري ومش مهم
سؤال 8

أي من العناصر دي Self-Closing (مش محتاج Closing Tag)؟

  • أ <p>
  • ب <div>
  • ج <img>
  • د <a>
سؤال 9

ما هو الاسم الصحيح للصفحة الرئيسية في أي مشروع؟

  • أ home.html
  • ب main.html
  • ج index.html
  • د start.html
سؤال 10

أي من أسماء الملفات دي صحيحة حسب Best Practices؟

  • أ My Photo.jpg
  • ب my_photo.jpg
  • ج my-photo.jpg
  • د MY-PHOTO.JPG

واجبات المحاضرة

5 مسائل تطبيقية متدرجة لتثبيت ما تعلمته

📌 الواجب الأول: بطاقة تعريف

ابني صفحة HTML بسيطة فيها:

  • عنوان رئيسي <h1> فيه اسمك
  • عنوان فرعي <h2> فيه عمرك أو دراستك
  • فقرة <p> فيها جملة تعريفية عنك
  • فقرة تانية فيها هواياتك (استخدم <strong> و <em>)

📌 الواجب الثاني: قائمة التسوق

ابني صفحة "قائمة التسوق" تحتوي على:

  • عنوان رئيسي "قائمة التسوق"
  • قائمة غير مرتبة <ul> فيها 8 عناصر على الأقل
  • قائمة مرتبة <ol> فيها خطوات الدفع في الكاشير (4 خطوات)
  • استخدم <strong> في اسم أهم عنصر

📌 الواجب الثالث: صفحة مفضلاتي

ابني صفحة فيها 3 أقسام (استخدم <h2> لكل قسم):

  • قسم "أفلامي المفضلة" — قائمة <ul> فيها 3 أفلام
  • قسم "كتبي المفضلة" — قائمة <ul> فيها 3 كتب
  • قسم "مواقعي المفضلة" — 3 روابط <a> لمواقع مفيدة
  • كل رابط يفتح في Tab جديدة (target="_blank")

📌 الواجب الرابع: معرض صور

ابني صفحة "معرض صوري" تحتوي على:

  • عنوان رئيسي "معرض صوري"
  • 4 صور على الأقل من مجلد images/
  • كل صورة ليها alt وصفي مناسب
  • كل صورة تحتها <p> فيه وصف صغير
  • استخدم <hr> للفصل بين كل صورة والتانية

📌 الواجب الخامس: التحدي — صفحة مدينة

ابني صفحة كاملة عن مدينة تحبها تجمع كل اللي اتعلمته:

  • عنوان رئيسي <h1> باسم المدينة
  • فقرة تعريفية فيها معلومات أساسية
  • عنوان <h2> "أشهر المعالم" + قائمة <ul> فيها 4 معالم
  • عنوان <h2> "أشهر الأكلات" + قائمة <ol> فيها 3 أكلات
  • صورة للمدينة مع alt وصفي
  • رابط لصفحة Wikipedia عن المدينة
  • رابط لفيديو يوتيوب عن المدينة
  • استخدم تعليقات <!-- --> لتنظيم الكود
  • نظم الملفات: index.html + images/ folder
